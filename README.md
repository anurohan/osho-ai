# Osho AI

An AI-assisted search and question-answering project built around a collection of Osho discourse material. The repository includes application code, discourse data, retrieval utilities, and a vector database.

## Project areas

- `app/` and `src/` contain application code.
- `data/` contains the discourse material used by the project.
- `vector_db/` stores retrieval data.
- `retrieval_test.py` provides a retrieval test utility.

Review the project configuration and `ADDING_DISCOURSES.md` before running or extending the system. Keep credentials and private configuration out of commits.
